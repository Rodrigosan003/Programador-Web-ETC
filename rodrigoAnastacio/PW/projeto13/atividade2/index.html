HTML Semântico

A semântica no HTML é importante para organizar e dar significado ao conteúdo de uma página web.

Início HTML CSS Contato

O que é HTML Semântico?

HTML semântico é a utilização de elementos que representam claramente o significado e a função do conteúdo apresentado em uma página web.

Em vez de utilizar apenas elementos genéricos, como div, podemos utilizar elementos que indicam a função de cada parte da página.

Principais elementos semânticos

Header

O elemento header representa o cabeçalho de uma página ou de uma determinada seção.

Nav

O elemento nav representa uma área destinada aos principais links de navegação.

Main

O elemento main representa o conteúdo principal da página.

Footer

O elemento footer representa o rodapé de uma página ou de uma seção.

Por que utilizar semântica?

A utilização de elementos semânticos facilita a organização do código, melhora a acessibilidade e ajuda os mecanismos de busca a compreenderem melhor o conteúdo da página.
